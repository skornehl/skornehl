### 🏠 What I'm currently building

My house runs on Home Assistant: gas boiler and wood-fired stove, a PV battery, EV charging, cameras,
Zigbee lights and a couple of wall-mounted screens. When a device or service has no integration, or
only half of one, I build the missing piece and publish it via HACS.

### 🧩 Home Assistant integrations

| Project | What it does |
|---|---|
| [**ha-vicare-extras**](https://github.com/skornehl/ha-vicare-extras) | Viessmann ViCare features the core integration doesn't expose. Read from its cache, so no extra API calls. |
| [**ha-jira-board**](https://github.com/skornehl/ha-jira-board) | Live two-way drag-and-drop Kanban board for Jira inside Home Assistant. Moving a card really transitions the issue. |
| [**ha-draytek-vigor**](https://github.com/skornehl/ha-draytek-vigor) | DSL line values (sync rate, SNR margin, errors) from the DrayTek Vigor 167 modem. |
| [**ha-todo-sync**](https://github.com/skornehl/ha-todo-sync) | Keeps two to-do lists in sync, e.g. the Alexa shopping list and Google Keep. |
| [**ha-chefkoch**](https://github.com/skornehl/ha-chefkoch) | Your saved chefkoch.de recipes, plus a step-by-step cooking mode for kitchen screens. |
| [**ha-google-photos-backup**](https://github.com/skornehl/ha-google-photos-backup) | Automatic Google Photos backup to a local disk (Picker API, rclone or Google Takeout import). |
| [**ha-kleinanzeigen**](https://github.com/skornehl/ha-kleinanzeigen) | Re-publish your own kleinanzeigen.de ads, images included, straight from Home Assistant. |
| [**ha-dls-mein-essen**](https://github.com/skornehl/ha-dls-mein-essen) · [**ha-blauart-kita**](https://github.com/skornehl/ha-blauart-kita) | School and daycare meal portals: daily menu, meal selection and attendance. |
| [**ha-addons**](https://github.com/skornehl/ha-addons) | Home Assistant add-ons that back some of the integrations above (headless-browser bridges). |
